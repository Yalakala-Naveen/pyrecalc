pyrecalc — playground

Excel formula evaluation without Excel, in your browser. Edit any cell — formulas start with = — and every result recomputes live. The evaluator on this page is a JavaScript port of the Python package, parity-verified against it (34/34 cases).

The Stored column is what a generated workbook claims its formula cells contain (the cached values Excel would have written). pyrecalc recomputes each formula and flags any cell whose stored value disagrees — the silent failure this tool exists to catch.

Python package: pip install pyrecalc (from Mon Nov 30, 2026) · Source: github.com/Yalakala-Naveen/pyrecalc · Built by Naveen Yalakala.
